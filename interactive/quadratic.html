Юу ажиглах вэ?

  • a > 0 үед параболын салаа дээш, a < 0 үед доош чиглэнэ; |a| ихсэх тусам парабол нарийсна.
  • c-г өөрчлөхөд парабол дээш, доош шилжиж, Oy тэнхлэгийг (0; c) цэгт огтолно.
  • Оройн цэг: m = −b / (2a), n = f(m). Тэгш хэмийн тэнхлэг нь x = m шулуун.
  • Оройг чирэхэд a хэвээр үлдэж, b = −2am, c = am² + n болж өөрчлөгдөнө.
  • D = b² − 4ac-ийн тэмдэг параболын Ox тэнхлэгтэй огтлолцох цэгийн тоог заана.
