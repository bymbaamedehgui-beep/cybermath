Шугаман функц y = kx + b

P, Q цэгийг чирж шулууныг тодорхойл, эсвэл k, b гулсуурыг хөдөлгө.

Функц

Юу ажиглах вэ?

  • k > 0 бол функц өснө, k < 0 бол буурна, k = 0 бол шулуун Ox тэнхлэгтэй параллель.
  • k = Δy / Δx: x нэг нэгжээр өсөхөд y нь k нэгжээр өөрчлөгдөнө.
  • b бол шулуун Oy тэнхлэгийг огтлох цэгийн ординат: (0; b).
  • tg α = k, энд α нь шулууны Ox тэнхлэгийн эерэг чиглэлтэй үүсгэх өнцөг.
  • Параллель шулуунууд: k₁ = k₂, b₁ ≠ b₂. Перпендикуляр шулуунууд: k₁·k₂ = −1.
